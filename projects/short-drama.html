《渣男出轨后，我嫁给了他叔叔》

项目定位

英文片名

I Married My Cheating Ex's Billionaire Uncle

类型

Billionaire Romance / Revenge / Contract Marriage / Family Business / Workplace Revenge

目标市场

美国、英国英语竖屏短剧市场

体量

60集 × 约60–90秒

核心轨道

A轨：无脑爽剧 / 狗血打脸型

核心卖点

婚礼抓奸、嫁给前任叔叔、“Aunt Emma”关系倒挂、豪门身份打脸、女主事业夺权、追妻火葬场

节奏标准

前3集完成抓奸、家庭压迫与叔叔登场；E8超级身份爽点；E10股权翻牌；前30集每集有明确冲突、爽点或卡点。

主线 / 支线 / 爽剧发动机

主线

Emma借契约婚姻脱离原生家庭控制，重回Carter Development，保住母亲留下的20%股份，最终夺回经营权。

感情线

从公开场合演夫妻，到护短、吃醋、危机反击，最终由复仇工具变成主动选择。

前任火葬场

Ryan从认定Emma一定回头，走向嫉妒、失权与彻底出局。

家庭夺权

继母与继姐从情感羞辱升级到抢客户、抢方案、伪造资历和股份争夺。

豪门女配

Claire先以体面与家世施压，后期制造假出轨丑闻，被Emma用证据反杀。

固定爽剧循环

公开羞辱 → 反派加码 → 身份/证据/能力翻牌 → 围观者倒戈 → 反派继续作死 → 下一轮更大打脸。

本地化改编

国内爆款底盘英语市场落法改编目的

家族联姻、长辈压迫

Family trust、集团控制权、地产项目融资

把“豪门”变成可理解的权力结构

嫁给前任长辈、辈分倒挂

“Aunt Emma”称谓与家族席位变化

保留最直接的关系爽点

夺家产、继承人之争

Board vote、股权、业绩与合规证据

让女主翻盘不只依赖丈夫身份

宴会、名媛与公开打脸

Gala、luxury brand、media scandal

换成英语观众熟悉的公开社交场

02 · 30集完整剧本

《亿万富翁的保洁新娘》

项目定位

英文片名

The Billionaire's Janitor Bride

类型

现代商战复仇 / 先婚后爱 / 契约婚姻 / 身份反转

目标市场

美国英语竖屏短剧市场

体量

30集 × 约90秒

核心案件

Sterling Pharmaceuticals隐瞒止痛药Veloxyn致命副作用；前FDA调查员Mia以保洁员身份潜入三年取证。

核心卖点

保洁员隐身身份、豪门契约婚姻、药企黑幕、卧底身份曝光、男主在家族与正义之间站队。

制作原则

每集1–2个可复用场景；人物开场已在场；台词短、情绪可演；最后5–10秒抛出下一集钩子。

爆点与情绪发动机

身份误判

所有人把Mia当成最好控制的保洁员，观众知道她一直在观察、记录和取证。

阶层打脸

泼酒、耳光、驱赶与晚宴羞辱，都被她转化为情报或公开反击。

案件推进

安全报告、批次数据、证词、录音、药瓶和银行记录逐步闭合证据链。

感情拉扯

Nathan以为自己选了无背景的新娘，最后为她公开对抗父亲与董事会。

关键反转

Nathan不是帮凶；他早已察觉卧底身份，等待Mia主动说出真相。

终局回报

契约婚姻从合同开始，以没有期限的承诺和一枚戒指结束。

本地化改编

国内爆款底盘英语市场落法改编目的

底层女性嫁入豪门

纽约药企保洁员 × 医药集团继承人

保留阶层反差，加入明确职业系统

隐藏身份与复仇

前FDA调查员卧底，围绕药品安全报告取证

让“隐藏大佬”变成可持续案件线

家族恶斗与继承

董事会、CEO问责、继承人限期婚姻

用公司治理承接豪门斗争

男主护妻

从删监控、挡枪到董事会公开指认父亲

把甜宠升级为价值选择

前10集爽点排布

E01签契约时偷到报告；Nathan放过系统警报E03婆婆泼橙汁，Mia当场点出受害者姓名E05被掌掴后证据与关系同步翻牌E08女主管下跪，妹妹的死亡批次进入证据链E10董事会身份反转，Nathan拿出U盘

核心场域

纽约模特经纪公司、Casting空间、摄影棚、合租公寓、时尚活动与品牌拍摄

核心发动机

普通新人上升线 + 前任头牌消失之谜 + “替代者”身份 + 成功诱惑 + 行业规则反噬

女性成长

The Wife in Apartment 3B

类型

Marriage Mystery / Female Suspense / Romance Thriller / Memory Mystery / Domestic Secrets

目标市场

美国英语市场；女性向真人竖屏短剧

体量

30集 × 约75秒

核心场域

婚宅、Apartment 3B、公寓走廊与邻居家、建筑事务所、旧康复记录相关空间

核心发动机

婚外情疑云 → 另一个“Emma” → 记忆缺口 → 丈夫谎言 → 七年前的自己留下证据 → 现在的Emma重新选择

悬念分层

第一层丈夫秘密支付三年房租，像长期养着情人第二层3B没有情人，却处处是Emma自己的生活痕迹第三层照片、衣物、录音和身体细节证明“她来过”中点3B是失忆前的Emma为离婚秘密租下的住所后半Noah是在保护她，还是借失忆抹掉了不利真相终局过去可以作证，但不能替今天的她做决定

英语市场开发

《我的祖母是神探》

项目定位

英文片名

My Grandmother Is a Detective

类型

现实罪案悬疑 / 双女主 / 代际关系 / 证据链叙事

目标市场

美国英语市场；AI仿真人竖屏短剧

体量

30集 × 约75秒

核心案件

1989年失款与2026年死亡案相互咬合；祖母与外孙女完成迟到三十五年的调查。

核心命题

当真相会摧毁熟悉的一切，是否仍愿意保存它、说出它，并承担自己的那部分责任。

生产交付

完整双语剧本、人物小传、30集剧情、逐集资产拆解与98项制作资产。

结构与抓人点

双时间线

1989年银行劫案与2026年伪装自杀案共用一条资金与人物关系链。

双女主

Claire负责追问，退休警探祖母Dot负责方法；调查同时变成两代人的互相审判。

非脸谱反派

Frank把控制包装成照顾，危险来自“可信任的熟人”，而不是暴力外形。

证据链推进

旧钥匙、烧焦账页、录音、监控、门禁记录与供述逐集改变判断。

程序反转

祖孙拒绝用非法搜查换取正确答案，转入合法监听，让真相能够成立。

情绪回报

Dot的胜利不是洗白，而是把自己的沉默也放进证词。

30集阶段

E01–05拒绝自杀结论，旧钥匙打开1989年案卷E06–11Frank进入视野，调查转为祖孙信任危机E12–17错误对象与祖母认罪，旧案真相改写E18–23录音、门禁与供述还原Megan之死E24–30合法监听、公开承担、Frank被捕
